📋 使用说明
1. 点击「打开浏览器登录」→ 系统会启动 Chrome 并打开平台首页
2. 在弹出的浏览器中手动登录（建议勾选"记住我"）
3. 登录成功后，浏览几个页面确保登录态生效
4. 回到本页面点击「提取Cookie保存」→ 系统从 CDP 导出 cookie 存入文件
5. 点击「刷新状态」确认登录态有效

注意：Cookie 会过期，建议每周检查一次。失效后重复上述步骤。
